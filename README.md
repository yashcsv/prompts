## 🛠 How to Use These Prompts

### Method A: As a System Instruction / Custom GPT / Project Knowledge
1. Copy the full markdown text of the desired prompt (e.g., `PROTOCOL T 800 LOOP.md` or `MASTER PROMPT CEO FOUNDER WORKFLOW.md`).
2. Paste it into:
   - **Claude Projects:** System Instructions or Project Knowledge.
   - **OpenAI ChatGPT:** Custom GPT Instructions or User System Prompt.
   - **Gemini Advanced:** System Persona / Custom Gem.
3. Provide your problem statement, code snippet, business document, or raw data as the initial user message.

### Method B: In-Session Activation (One-Shot Execution)
Prefix your task with the master directive:
```markdown
[PASTE PROMPT BLOCK HERE]

---
OPERATING CONTEXT:
Task: Review our B2B SaaS retention funnel and diagnose Month 2 drop-off.
Data: [Insert Metrics/Code/Transcript]
```

## 🧠 Prompt Engineering Philosophy

Every prompt in this collection adheres to five core design principles:

```
               ┌───────────────────────────────┐
               │    Zero Hallucination Bias    │
               │ Epistemic labeling & citations│
               └───────────────┬───────────────┘
                               │
       ┌───────────────────────┴───────────────────────┐
       ▼                                               ▼
┌──────────────────────────────┐        ┌──────────────────────────────┐
│  Multi-Persona Scrutiny      │        │    Forensic Root Cause       │
│  Forces peer model review    │        │  Treats cause, not symptoms  │
└──────────────┬───────────────┘        └──────────────┬───────────────┘
               │                                       │
       ┌───────┴───────────────────────────────────────┴───────┐
       ▼                                                       ▼
┌──────────────────────────────┐        ┌──────────────────────────────┐
│  Stateful Recursive Loops    │        │   Zero Conversational Fluff  │
│ Self-audit before outputting │        │  High-density decision data  │
└──────────────────────────────┘        └──────────────────────────────┘
```

1. **Epistemic Labeling:** Explicitly stating certainty tiers (High / Medium / Speculative) prevents confident hallucinations.
2. **Recursive Loop Auditing:** Directing the model to silently critique its own line of reasoning before finalizing tokens.
3. **Domain Density Over Fluff:** Elimination of pleasantries, preamble, and apologetic tone in favor of structured data, matrices, and actionable execution checklists.
